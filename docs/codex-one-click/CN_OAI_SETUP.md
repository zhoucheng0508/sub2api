# 国模 OAI 专用接入

仅 `platform=openai` 且分组名称去除空白后等于 `国模OAI`（英文大小写不敏感）时启用。
普通 OpenAI、Composite 和其他分组沿用原有流程。国模 OAI 也保留原来的指南、CC Switch 导入和通用脚本，
额外增加「国模 OAI 一键配置」选项，不替换原来的入口。专用页面目前面向 Windows 10/11。

## 用户流程

1. 先安装并启动一次 CC Switch 和 Codex，关闭代理接管、保存编辑，从托盘菜单完全退出 CC Switch。
2. 在 API 密钥页选择国模 OAI 分组的密钥，进入一键接入，选择 Codex 和「国模 OAI 一键配置」。
3. 下载 `sub2api-cn-oai-setup.cmd`，双击运行，无需管理员权限。
4. 完成后重启 Codex。之后在 CC Switch 中直接切换供应商。

脚本不会强制关闭 CC Switch；检测到仍在运行时停止并提示用户退出。
模型名可留空，默认选择目录中第一个具有多个推理档位的模型，没有则选择第一个模型。
指定的模型不在当前目录中时停止，不偷偷换成 GPT 默认模型。
下载文件包含密钥，应按密钥文件保存，不要转发。

## 持久化

脚本使用 Bearer 请求本站 `/v1/models?client_version=0.147.0`，禁止跳转；
验证数组与字段类型、非空目录、重复模型、允许的档位及输入类型后，再让用户安装的 Codex
同时解析合并后的 TOML 和下载目录，从而检查 `description`、`base_instructions` 等当前客户端必需字段。
不执行模型目录中的任何指令。

Codex 路径优先使用 CC Switch 的 `codexConfigDir`，其次为 `CODEX_HOME`，最后为用户目录的 `.codex`。
前两者同时存在且不一致时停止，避免写错目录。中文和空格路径使用 UTF-8 和 LiteralPath 处理。

目录文件按接入地址和分组 ID 命名为 `codex-cn-oai-<标识>-models.json`，不同站点的目录不会互相覆盖。
同一站点和分组重复运行会更新已有专用供应商，不重复创建。

CC Switch 的普通 deeplink 会重建配置并丢弃 `model_catalog_json`，因此脚本通过 Windows 自带的
`winsqlite3` 将完整供应商配置写入已有 `cc-switch.db`，并同步 `settings.json` 中的当前 Codex 供应商。
只更新专用供应商及 Codex 当前选择，不改其他供应商内容或公共配置。专用供应商关闭公共片段合并，
使用保留原有用户设置的完整配置，防止公共片段把模型目录或推理档位覆盖掉。
数据库结构不兼容时停止；不自动迁移 CC Switch 数据库。
自定义 CC Switch 数据目录可通过 `SUB2API_CC_SWITCH_DIR` 指定。

模型目录、Codex 配置和 CC Switch 配置均先备份，数据库写入使用事务。
中途失败会回滚数据库并恢复已备份文件。备份目录包含 `restore.ps1` 和文件路径清单；
手动恢复前须退出 CC Switch，恢复会还原该备份时的 CC Switch 数据库。
安装及恢复共用互斥锁。文件写入前保存持久化日志，数据库事务内记录提交标志；
下次运行成功连接数据库后先恢复未提交安装的文件。文件指纹不匹配时停止，不覆盖后续修改。
完整恢复会检查安装后的文件、数据库和 WAL/SHM 指纹，发现后续修改就拒绝恢复；
符合恢复条件时也先备份当前文件，再还原旧备份。
保留 profile 和上下文设置；修改活动 profile 中必要的模型字段，不改其沙箱和审批选项。
使用用户安装的 Codex 解析器在正式写入前验证原始及合并后的配置。当前 Codex 已不支持某些
旧 profile 形式，遇到解析器拒绝时停止，保留原文件，不自动停用用户 profile。
为避免破坏复杂配置，当前自动合并不处理包含 TOML 多行字符串的配置，遇到时停止并显示原因。

## 能力声明

后端 `codex_cn_oai.go` 按运营者要求消除该分组的本地能力限制，为分组目录中的每个模型开放
图片输入、原始图片细节及 `none/minimal/low/medium/high/xhigh/max/auto` 档位，默认 `medium`。
新模型也适用；不向分组添加额外模型，分组白名单仍然有效。参考 JSON 中原来仅有 `none` 的
16 个模型现在也可以在客户端选择档位。这是客户端选项的显式开放，不是上游能力探测结果。
不复制参考文件的提示词，也不把其 `supports_search_tool=false` 变更应用到工具发现。
这是该分组的运营配置，不代表上游能力已经逐个实测，实际图片处理和推理参数仍取决于上游。
旧下载文件不含目录内容，每次运行都会重新下载最新目录。已经安装的旧目录需要重新运行
专用脚本更新，然后在 CC Switch 选择该供应商并重启 Codex；仅刷新网页不会更新本地目录。

## 验证

- Go 测试覆盖分组隔离、白名单成员保持、能力声明和其他元数据保留。
- Vue 测试覆盖专用入口、下载 CMD 和切换回普通分组。
- Windows 集成测试运行真实 CMD、PowerShell 5.1、Windows SQLite，使用临时目录及数据库，
  覆盖中文路径、重复安装、`none` 档位、下载失败和写入失败回滚。
- 测试中网络与应用进程操作被替换为隔离桩，不调用真实模型，也不重启开发者的 CC Switch。
