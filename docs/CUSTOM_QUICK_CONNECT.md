# 开始使用：场景引导接入

采用 A 方案：独立的 `/get-started` 页面，按“账户就绪 → 用途与应用 → 同页创建或选择密钥 → 安装、导入、验证”引导用户。新用户不必先去 API 密钥页。密钥管理仍可仅传递密钥 ID 跳转到引导页，不传递密钥正文。RikkaHub 导入不再出现在产品入口中。

## 完整首次接入流程（第二轮）

- 普通邮箱注册完成后默认进入 `/get-started`，包括邮件验证后的注册完成。明确的安全返回路径、管理员默认页、OAuth/绑定回调的原有语义继续保留。
- 第三方回调没有可靠的新账号标记，不强制改写所有 OAuth 返回地址。普通用户首页在成功读取到 `total_api_keys === 0` 时展示新手引导，加载中或请求失败不误判为新用户。
- 在引导页直接调用现有用户分组与密钥创建 API，仍由后端控制账号权限和订阅资格。单一分组可预选，多分组要求用户明确选择；不自动购买、充值或调用模型。
- 创建成功后保持用途与所选应用，自动选中新密钥并继续安装/接入。生图组要求与画布相同的 `openai + image_only + allow_image_generation` 能力标记，原生和固定输出分组仍独立。
- 创建期间锁定会卸载表单的局部切换，禁止重复提交。账号身份切换会丢弃旧结果；同账号 token 刷新不打断创建。网络结果不确定时可在本页重新读取已有密钥，不自动重试创建。
- “API 密钥”是后续查看、停用、修改额度等管理入口；手动配置继续可用。

## 入口与行为

- 用户侧栏、管理员“我的账户”、简单模式及用户概览提供“开始使用”。
- API 密钥页顶部入口不依赖当前表格页；每行“接入应用”带入该行密钥，创建密钥后提供“立即接入”。手动配置保留。
- 全部分页读取成功后才展示密钥列表；请求失败可重试，离开页面或切换登录身份会中止旧请求。
- 失效、停用、额度耗尽、未分组及生图专用密钥不参与文本自动配置。显式选择的密钥失效后，不静默替换成其他分组。
- 首屏展示 Codex、Claude Code、OpenCode，其他现有客户端放在“更多客户端”。自动配置组合未适配时保留手动配置，不宣称模型或上游不可用。
- 首次安装指引默认展开；已安装的用户可跳过。版本、芯片架构、模型覆盖和配置脚本放在高级选项中。
- 国模 OAI 的 Windows 专用 CMD 是该分组的主要配置动作，保留模型发现、配置备份与恢复行为；非 Windows 不提供错误的通用替代。
- 发起 CC Switch 协议后显示待确认状态。网页没有检测到应用打开时提供重试与安装说明，不宣称已成功导入或确定未安装。
- 图片创作只导航到现有受信任的工作站入口，说明在工作站中选择相应生图密钥、连接渠道和生成/编辑图片。原生和固定输出仍使用原来的独立分组，不更改价格、模型或上游。

## 维护边界

接入界面复用 `QuickConnectPanel.vue`，原 `CodexOneClickModal.vue` 保留兼容包装。生成配置、CC Switch 端点归一化、余额查询和 Codex/CN-OAI 脚本继续使用现有工具函数。定制文案、页面辅助函数和测试集中在 `frontend/src/custom/vote-ai/quick-connect/`。

RikkaHub 历史模块仍保存在 Git 源码中供追溯，但产品不再导入其组件、显示标签或加载其二维码功能；全局语言注册保留，以满足现有源文件语言键检查。

本轮不修改数据库结构、后台服务、模型接口、上游凭证或权限。页面不自动发起付费模型验证，用户自行在客户端发送消息确认连接。

## 验证

- 第一轮 128 项定向测试覆盖统一入口、分页、密钥资格、RikkaHub 移除与既有配置行为。第二轮追加/调整注册与邮箱验证跳转、首次访问提示、同页创建、重复提交与身份隔离、原生/固定输出分组过滤、创建后选择、兼容配置及语言键检查。
- TypeScript 检查、变更文件 ESLint 检查与生产前端构建。
- 雨云部署前保存完整 Compose 参数、原镜像和数据库备份；仅重建 `app`，检查并重载原 nginx。其余容器保持不变。
- 部署记录与确切回滚命令保存在本轮工作记录；生产发布与雨云验收分别记录，不将测试部署等同于生产发布。
